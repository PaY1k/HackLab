## Перед защитой (за 2–3 часа)

- [ ] `make bit` на ноутбуке стенда: в конце `TIMING OK`, в `reports/cdc.txt` нет критичных предупреждений.
- [ ] Два проверенных битстрима: текущий и предыдущий рабочий (`cp audio_nexys_a7.bit backup_vN.bit`), git-тег на каждом.
- [ ] Прошить, пройти **все 6 треков** и MIDI по сценарию ниже, проверить сброс CPU_RESETN.
- [ ] SD-карта с двумя треками (`tools/prepare_sd.sh`), запасная копия файлов на ноутбуке.
- [ ] Прошивка во flash (`make flash`, JP1 = QSPI): плата стартует сама после переключения USB на Windows-ПК.
- [ ] Программа на Windows видит COM-порт и клавиатуру; при нажатии клавиш мигают LD0 и LD1 на плате.
- [ ] Запасное видео демо на 1 минуту (телефоном с монитора и звуком) — на случай, если стенд откажет.
- [ ] Громкость наушников / колонки проверена заранее, на демо стартовать с громкостью 10.
- [ ] Три прогона сценария вслух с таймером.
- [ ] Заморозка: после этого — только исправления, никаких новых функций.

## Вопросы жюри, которые стоит ожидать

**Почему нет MP3 на самой плате?** Декодер MP3 — это обратное MDCT, Хаффман и десятки миллионов операций в секунду; чистый HDL-декодер за хакатон нереален (так написано и в материалах организаторов). Мы сделали аппаратный разбор FAT32 и WAV (MP3 перегоняется в WAV скриптом), есть и режим потока звука с ПК. Следующий шаг — софт-процессор с библиотекой Helix MP3.

**Как MIDI попадает в ПЛИС?** Клавиатура -> программа на Python -> строки `ON 60 100` / `OFF 60` по USB-UART 115200 -> `uart_rx` -> `midi_text_rx` (разбор текста на лету, понимает и формат mido) -> свободный голос синтезатора; если голосов не хватает, занимается самый старый.

**Как вы боролись с щелчками?** Огибающая ADSR у каждой ноты, плавное изменение громкости за ~20 мс на паузе и смене трека, усилитель не выключается (тишина — середина шкалы ШИМ).

**Почему 48 кГц и 10 бит?** 49.15865 МГц / 1024 = 48 006 Гц: один период ШИМ = один сэмпл. 10 бит мало, поэтому noise shaping: ошибка округления переносится в следующий сэмпл, шум уходит выше слышимого диапазона.

**Как файл 44.1 кГц играет с правильной высотой?** `stream_reader` берёт сэмплы из FIFO со своим фазовым счётчиком: шаг = частота файла / 48006 · 65536.

**Как данные идут между клоками?** Статус — handshake (`cdc_bus`), потоки — асинхронные FIFO с указателями в коде Грея, осциллограф — двухпортовая BRAM с двойной буферизацией, одиночные сигналы — два триггера. Vivado `report_cdc` — в `reports/cdc.txt`.

**Что будет, если вынуть SD-карту?** Контроллер ловит ошибку, плеер пишет «SD: нет карты» и переподключает карту, когда её вставят.

**Как проверяли?** Самопроверяющиеся тестбенчи в Icarus Verilog: FIFO, протокол с ПК, звуковой тракт (высота нот по WAV), SD-плеер против модели карты с образом FAT32 — каждый отсчёт сравнивается с эталоном. Экран рендерится из моделирования в PNG.

**Сколько ресурсов?** Цифры из `reports/utilization.txt` после `make bit` — вписать на слайд.
