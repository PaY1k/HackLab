# SBER AUDIO — музыкальный плеер на ПЛИС

Плеер на плате Digilent Nexys A7 (ПЛИС `xc7a100tcsg324-1`), SystemVerilog, без процессора: весь звук, файловая система SD-карты и интерфейс на VGA сделаны логикой.

![Экран плеера](doc/image/ui_play.png)

Кадры получены моделированием всего плеера (`src/sim/top_audio.sv`) в Icarus Verilog: [мелодия](doc/image/ui_play.png), [синтезатор, треугольная волна](doc/image/ui_synth.png), [трек SD без карты](doc/image/ui_sd.png), [заставка](doc/image/ui_splash.png).

## Что умеет

| № | Трек | Откуда звук |
|---|---|---|
| 01 | Синтезатор нот | DDS, нота кнопками, октава переключателями, звук из настроек синтезатора |
| 02 | Коробейники | мелодия из блочной памяти (BRAM) |
| 03 | Ода к радости | мелодия из BRAM |
| 04, 05 | первые два файла `*.WAV` с microSD | FAT32, WAV 8/16 бит, моно/стерео, любая частота дискретизации |
| 06 | поток с ПК | любой файл (MP3 тоже), ПК декодирует и шлёт по USB-UART (бинарный режим, `PC_TEXT_MIDI = 0`) |
| — | MIDI-клавиатура | через ПК текстом по UART 115200, 8-голосный настраиваемый синтезатор поверх любого трека |

Качество звука:

* 10-голосный DDS-синтезатор: синус, треугольник, меандр, пила; огибающая ADSR, вибрато, pitch bend, сдвиг октавы — всё настраивается кнопками или с ПК;
* громкость по логарифмической шкале (шаг 2 дБ), все изменения плавные (~20 мс): пауза, громкость и смена трека без щелчков;
* ШИМ 10 бит / 48 кГц с noise shaping первого порядка: шум квантования уходит выше звукового диапазона;
* выход на открытом стоке, усилитель не выключается: тишина = середина шкалы, без хлопков.

Экран 800×600: танцующая Сбер-тян (пиксель-арт, танцует, пока играет музыка или MIDI), плейлист, осциллограф с триггером, пианино на 3 октавы (подсвечиваются звучащие ноты, в том числе с MIDI-клавиатуры), время, длительность и прогресс трека, громкость, русский шрифт, дизеринг без полос на градиентах.

## Быстрый старт

Нужны Vivado 2023.2 (`source /tools/Xilinx/Vivado/2023.2/settings64.sh`), Python 3, для проверок Icarus Verilog. Полный список: [doc/DEPENDENCIES.md](doc/DEPENDENCIES.md).

```bash
make bit        # синтез + имплементация без GUI (~10 мин): audio_nexys_a7.bit и reports/
make program    # прошить плату по USB (до выключения питания)
make flash      # записать во flash: плата грузит плеер сама при включении (JP1 = QSPI)
```

`make bit` в конце печатает `TIMING OK` или `TIMING FAILED`, подробности в `reports/timing.txt`, переходы между клоками в `reports/cdc.txt`.

```bash
make deploy                              # проект Vivado с GUI (как в демо)
make test                                # проверки в Icarus Verilog (~2 мин), без Vivado
make test-sd                             # SD-плеер против модели карты (~4 мин)
cd src/sim && make && ./obj_dir/audio    # симулятор Verilator + SDL2: звук и экран в окне
```

Для проверок без Vivado: `sudo apt install iverilog`, `pip install pillow`.

## Управление

| На плате | В симуляторе | Действие |
|---|---|---|
| BTNC | Пробел | play / pause |
| BTNU / BTND | ↑ / ↓ | громкость (0…15, старт 10) |
| BTNL / BTNR | ← / → | предыдущий / следующий трек |
| SW15 + BTNL / BTNR | N, затем ← / → | на треке 01: предыдущая / следующая нота |
| SW[2:0] | 1 … 8 | октава синтезатора (1…8) |
| SW14 | M | меню синтезатора: BTNU/BTND — пункт, BTNL/BTNR — значение |
| CPU_RESETN | — | сброс |

Семисегментные индикаторы: `1 10  C4` — номер трека, громкость и нота, которая звучит сейчас (с MIDI-клавиатуры, из мелодии или синтезатора); точка после буквы — диез (`F.5` = F#5), `--` — тишина.

## Настройки синтезатора

Включите **SW14** — вместо осциллографа появится меню «СИНТЕЗАТОР ДЛЯ MIDI». BTNU/BTND выбирают пункт, BTNL/BTNR меняют значение, выключите SW14 — меню закроется, настройки останутся.

| Пункт | Значения | Команда с ПК |
|---|---|---|
| Волна | синус, треугольник, меандр, пила | `WAVE SAW`, `WAVE SINE`, `WAVE TRI`, `WAVE SQUARE` |
| Атака | 0…15 (0 мс … 2 с) | `ATTACK 6` |
| Спад | 0…15 | `DECAY 5` |
| Сустейн | 0…15 (уровень удержания) | `SUSTAIN 11` |
| Затухание | 0…15 (после отпускания клавиши) | `RELEASE 12` |
| Вибрато | 0…15 (+ колесо модуляции клавиатуры) | `VIBRATO 4` |
| Октава | −2…+2 для MIDI | `OCTAVE 3` (2 = без сдвига) |
| Громкость | 0…15 громкость MIDI | `MVOL 10` или `CC 7 <0..127>` |

Колесо pitch bend клавиатуры двигает высоту на ±2 полутона (`BEND -8192..8191`), колесо модуляции добавляет вибрато (`CC 1 <0..127>`). Настройки действуют на MIDI-голоса и синтезатор трека 01, мелодии из BRAM звучат как прежде.

Примеры звука: «орган» — `WAVE SQUARE`, `ATTACK 2`, `RELEASE 4`; «пэд» — `WAVE TRI`, `ATTACK 11`, `RELEASE 13`, `VIBRATO 3`; «бас» — `WAVE SAW`, `OCTAVE 0`, `DECAY 7`, `SUSTAIN 6`.

## Музыка с SD-карты

Карта в FAT32 (карты до 32 ГБ обычно уже такие). Плеер играет первые два файла `*.WAV` из корня карты. Скрипт перегонит любые файлы, в том числе MP3:

```bash
tools/prepare_sd.sh /media/$USER/SDCARD "мой трек.mp3=CARTI" другой.mp3=MYSONG
```

Получатся `CARTI.WAV` и `MYSONG.WAV` (16 бит, моно, 48 кГц); имя после `=` — до 8 латинских букв и цифр, его и видно на экране (треки 04 и 05). Без `=ИМЯ` файлы будут `TRACK1.WAV`, `TRACK2.WAV`. В корне карты не должно быть других `.WAV`: плеер берёт первые два. Если карты нет, в плейлисте написано «SD: нет карты»; карту можно вставить на ходу, плеер переподключится сам.

## MIDI-клавиатура через ПК (UART)

Клавиатура подключена к Windows-ПК, программа на Python шлёт ноты на плату текстом по USB-UART: **115200 бод, 8N1, одна команда на строку** (конец строки `\n`, `\r` или `;`, регистр не важен):

| Строка | Действие |
|---|---|
| `ON 60 100` | нажата нота 60 (C4) с силой 100; сила 0 = отпущена |
| `OFF 60` | отпущена нота 60 |
| `OFF`, `STOP`, `PANIC` | отпустить все ноты |
| `60 100` / `60 0` | просто номер ноты и сила |
| `note_on channel=0 note=60 velocity=100 time=0` | то, что выдаёт `str(msg)` в mido |
| `note_off channel=0 note=60 velocity=0 time=0` | |
| `control_change channel=0 control=123 value=0` | все ноты выключить |
| `BEND -4096` / `pitchwheel channel=0 pitch=-4096 time=0` | изгиб высоты, −8192…8191 = ±2 полутона |
| `CC 1 64` / `control_change channel=0 control=1 value=64` | колесо модуляции → вибрато |
| `SET ATTACK 6`, `ATTACK 6`, `WAVE SAW`, `SET 1 6` | настройки синтезатора (раздел выше) |

Ноты — номера MIDI (60 = C4, 69 = A4 = 440 Гц), играют 8 голосов одновременно поверх любого трека, на экране загораются клавиши пианино (C3…B5). Разбор: `src/rtl/midi_text_rx.sv`, проверка: `make test-midi`.

**Подключение.** У Nexys A7 один USB-разъём и для прошивки, и для UART, и для питания. Если прошить плату с Linux и переткнуть кабель в Windows-ПК, прошивка пропадёт. Поэтому:

```bash
make bit && make flash      # на Linux: прошивка записывается во flash платы
```

Перемычку **JP1 поставить в QSPI** — теперь плата сама загружает плеер при каждом включении. Кабель в Windows-ПК, плата появится как `USB Serial Port (COMx)` в диспетчере устройств. Проверить без своей программы:

```powershell
pip install pyserial mido python-rtmidi
python tools\midi_uart_send.py --list
python tools\midi_uart_send.py --port COM5 --scale        # гамма и аккорд
python tools\midi_uart_send.py --port COM5 --midi auto    # клавиатура -> плата (с bend и mod)
python tools\midi_uart_send.py --port COM5 --set "WAVE SAW" --set "RELEASE 12"
```

Светодиоды платы для отладки: **LD0** — пришёл байт по UART, **LD1** — команда понята, **LD2** — звучит нота, **LD3** — SD-карта готова. Если LD0 мигает, а LD1 нет — строки приходят, но в другом формате.

Бинарный протокол на 921600 бод с потоком звука (`tools/pc_player.py`, трек 06) включается параметром `PC_TEXT_MIDI = 0` в `src/rtl/player_top.sv`.

## Как устроено

```
 кнопки ─> debounce ─> player_ctrl ─────────────┐
                                                ▼
 BRAM мелодии ──> melody_player ──> poly_synth (10 голосов, ADSR) ─┐
 MIDI (UART) ───────────────────────────────┘                      ├─> audio_core: микшер, громкость,
 microSD ─> sd_card (SPI) ─> sd_player (FAT32, WAV) ─> FIFO ───────┤   плавные переходы, ШИМ + noise shaping ─> AUD_PWM
 USB-UART ─> pc_link (пакеты, кредиты) ─> FIFO ────────────────────┘
                                                │ статус, маска нот, сэмплы
                                                ▼
 screen_text_ctrl ─> async FIFO ─┐   cdc_bus, scope_capture (двойной буфер)
                                 ▼                 ▼
                         player_screen: display_ctrl + vga_ui ─> VGA 800×600
```

Клоки: `clk_audio` 49.15865 МГц (весь звук, SD, UART), `pixel_clk` 39.941 МГц (экран), 5 МГц (сброс, индикаторы). Между доменами только безопасные переходы: `cdc_bus` (handshake), асинхронные FIFO с указателями Грея, двухпортовая BRAM осциллографа, синхронизаторы на два триггера.

Всё, кроме клоков, сбросов и дебаунсеров, собрано в `src/rtl/player_top.sv`: этот же модуль работает и на плате, и в симуляторе.

## Проверки

| Проверка | Что проверяет | Как запустить |
|---|---|---|
| `tb_async_fifo` | 20 000 слов через FIFO между несвязанными клоками: порядок, без потерь | `make test` |
| `tb_midi_text` | текстовые MIDI-команды по UART 115200: 14 строк в разных форматах | `make test`, `make test-midi` |
| `tb_midi_system` | весь плеер: `ON 69 100` по UART -> звук 440 Гц, `OFF` -> затухание, светодиоды | см. файл |
| `tb_pc_link` | UART-пакеты: звук, MIDI (on / off / velocity 0 / all off), название, кредиты | `make test` |
| `tb_audio_core` | высота нот (A4 = 440.0 Гц), мелодия, пауза, плавность; пишет WAV | `make test` → `build/audio_core.wav` |
| `tb_sd_player` | модель SD-карты с образом FAT32: монтирование, каталог, цепочка кластеров, WAV 16 бит моно и 8 бит стерео — каждый отсчёт сверяется | `make test-sd` |
| `tb_vga_ui` | рендер кадра экрана в PNG | см. ниже |

```bash
iverilog -g2012 -o /tmp/ui -s tb_vga_ui src/rtl/display_ctrl.sv src/rtl/sber_logo_rom.sv src/rtl/vga_ui.sv src/tb/tb_vga_ui.sv
cd src/rtl/mem && vvp -n /tmp/ui +FRAMES=2 +OUT=/tmp/frame.txt && cd -
python3 tools/frame_to_png.py /tmp/frame.txt frame.png
```
